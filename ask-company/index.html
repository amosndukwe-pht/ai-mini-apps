      How production would use Glean

      In production the search step is Glean’s Search API, called with the signed-in person’s bearer token, so hits stay limited to documents that person can open. Number those hits the same way and pass the snippets to Claude with the prompt below. Glean’s Chat API is the other path, if Glean should draft the answer instead of Claude. This page ranks a bundled corpus in the browser and applies the role filter locally. It does not contact Glean. The sample files ship with the page, so the filter demonstrates retrieval, and is not an access-control boundary.
