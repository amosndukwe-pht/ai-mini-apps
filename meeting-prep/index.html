How this would call Glean

In production the search step is Glean’s Platform Search API: POST /api/search, with the signed-in person’s bearer token and the SEARCH scope, so results stay limited to what that person can open. Number the hits the same way and pass the snippets to Claude. Glean Chat is a separate call, if you want Glean to draft instead.
